# Open KainCheck

Double-click **Launch_KainCheck.bat** to open the public website in your default browser. No ChatGPT account is required to open it. Internet access is needed.

On the app welcome screen, choose **Continue demo as guest** to try it without a KainCheck account. Guest data stays in that browser. KainCheck account sign-in is separate from ChatGPT sign-in.

## Files in this GitHub folder

- `dist/`: app screens, themes, fonts, food photos and Vibe photos.
- `worker/`: server-side AI connections. API keys stay in hosting secrets.
- `scripts/`, `tests/`, `data/`, `supabase/`: project development and backend files.
- `project-files/documentation/`: latest combined document and interview files.
- `project-files/presentations/`: updated PowerPoint.
- `project-files/design/`: design mockups and their prompts.
- `project-files/verification/`: screenshots and verification results.
- `project-files/archive/`: older documents, slides and the original standalone HTML demo.

`project-files/` is a local organization folder, excluded from Git and from the hosted app. Original working copies have been preserved. Use the hosted app for the latest demo; archived HTML predates the current features.

Changes to GitHub source do not automatically update the hosted site. Follow the existing Sites publication workflow when updating it.
